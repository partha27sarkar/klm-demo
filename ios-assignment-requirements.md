# iOS Assignment

## Requirements

- Create a public or private GitHub repository for the assignment.
- When the assignment is complete, add the following reviewers to the repository:
  - `dimakalachniuk`
  - `kyrillvanseventer`
- Build an app using a data source of your choice.
- Consume an API of your choice. You may choose one from [Public APIs](https://github.com/public-apis/public-apis) or another source.
- Include at least:
  - An overview screen that displays multiple results.
  - A detail screen that displays additional information about a selected result.
- Support both iPhone and iPad.
- Choose either SwiftUI or UIKit for the user interface.
- Persist the data locally.
- Use whichever libraries you prefer or are accustomed to.

## Review criteria

The assignment will be reviewed for:

- Scalability
- Testability
- Maintainability
- Overall quality

## Other considerations

- Error handling
- Consistency
- Naming
- Architecture
